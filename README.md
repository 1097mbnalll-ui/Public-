# مسار — مساعدك الشخصي

موقع عربي (RTL) لإدارة الجامعة والعمل والحياة في مكان واحد. يعمل على الجوال والكمبيوتر، ويمكن تثبيته كتطبيق (PWA). **كل البيانات محفوظة على جهازك فقط.**

## ماذا يفعل

- **اليوم:** خطة مرتبة بالأولوية والموعد، لا تتجاوز وقتك المتاح. ينبهك إذا حمّلت يومك أكثر مما يحتمل، ويقترح ما تنقله للغد (ولا يقترح أبدًا ما لا يحتمل التأجيل). كل عنصر يُظهر سبب ترتيبه.
- **إضافة سريعة بالعربي:** «اطبع ملف العقد بكرة 10ص مهم #عمل 30د» ← تاريخ ووقت وأولوية ومجال ومدة. وكتابة اسم قالب («معاملة …») تُنشئ إجراء عمل بخطواته.
- **إجراءات العمل:** خطوات من أنواع (تنفيذ، طباعة، حفظ، تصديق، إرسال، انتظار رد، متابعة) مع الجهة ومكان الحفظ، وحقول مرنة، وسجل زمني، وقوالب قابلة لإعادة الاستخدام. تُجمّع حسب «بانتظار الطباعة / الإرسال / الرد…». خطوات الإرسال تتطلب تأكيدك لأن الموقع لا يرسل شيئًا بنفسه.
- **الدراسة:** مواد وفصول بأحجامها وصعوبتها، واختبارات. يقدّر الوقت المتبقي كنطاق (أقل–أكثر) من سرعتك الفعلية المقاسة من جلساتك، ويحاكي الأيام حتى الاختبار: كم يوميًا، آخر موعد مريح للبدء، متى تنهي المنهج، وما الفصول التي لن تصل إليها إن كنت متأخرًا مع خطة بديلة.
- **يتعلم منك:** يقارن تقديراتك بالوقت الفعلي ويصححها، ويتتبع التأجيل المتكرر.
- **التذكيرات:** إشعارات المتصفح (والموقع مفتوح)، وما يفوتك يظهر عند الفتح، وتصدير للتقويم (.ics) للتنبيه المضمون.
- **الأمان:** حفظ تلقائي (IndexedDB + نسخة في localStorage)، لقطات يومية آخر 14 يومًا، تراجع عن العمليات، تصدير/استيراد نسخة احتياطية.

## التشغيل محليًا

```bash
npm install
npm run dev      # تطوير
npm test         # اختبارات المحرك
npm run build    # نسخة الإنتاج في dist/
```

## النشر

كل دفع إلى `main` يبني الموقع وينشره على GitHub Pages عبر `.github/workflows/deploy.yml`.
مرة واحدة فقط: من إعدادات المستودع ← **Pages** ← **Source: GitHub Actions**.

## البنية

- `src/lib/engine/` — المنطق: الأولويات وخطة اليوم (`planner`)، خطة المذاكرة (`study`)، التعلم من بياناتك (`learning`)، التنبيهات (`insights`).
- `src/lib/` — نموذج البيانات، الحفظ، الإجراءات، التحليل اللغوي للإضافة السريعة، التذكيرات، النسخ الاحتياطي.
- `src/pages/`, `src/ui/` — الواجهة (React).
